## C3 판단

임계값 1.15배는 유지하고 측정 방법을 바꿨다.

- B의 6회 중 3회 실패는 재현하지 못했다. 합본에서 기존 측정 12회의 비율은 0.85~0.99였다(약 16fps).
- 스펙에 실제 문제가 2개 있었다. 기존 시작 좌표는 B의 교실에서 화분에 막혔고, 시작·끝 두 점 비교는 프레임 간격의 영향을 그대로 받는다.
- 수정: 가구가 없는 구간에서 700ms 동안 표본을 뽑아 기울기로 측정한다.
- 결과: 정상 코드 8/8 통과. B의 실제 코드에서 대각선 정규화를 제거한 결함은 4/4 탐지했다.

- ENV-2 원인 확인: 02:49 `verify` 중단은 A의 Next 서버 일괄 종료 때문이었다.
