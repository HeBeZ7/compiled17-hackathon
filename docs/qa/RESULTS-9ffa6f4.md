## 3. 사진 좌우 잘림 확인

**이 커밋에서 사진 외형의 좌우 잘림은 재현되지 않는다.** B가 실행하지 않았던 경로로 확인했다.

- 경로: `/create`의 실제 `avatar-photo-input` → 입장 버튼 → 서버 저장 → 교실의 `renderUrl` 표시 (V6, 양 화면).
- 판정: 교실 캔버스 캡처에서 사진 색 영역의 폭/높이 비율. C의 render는 원형이므로 잘리지 않으면 약 1이다. 기준은 0.96 초과 1.04 미만이고 양 화면에서 통과했다.
- 대조: 임시 복사본에서 `characters.ts`만 수정 전(`e4b0635`)으로 되돌리면 V6이 양 화면에서 실패했다. 비율은 desktop 0.895, narrow 0.892다.
- 캡처를 직접 보았다. 양 화면 모두 흰 외곽선까지 온전한 원형이고 좌우가 평평하게 잘린 부분이 없다.

한계: 입력은 단색 PNG 정사각형 이미지다. 실제 사진, 비정사각형 사진, 크롭 위치·확대를 조정한 경우는 이 사례로 판정하지 않았다.
